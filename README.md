# スクリーンカーテン

ページをオーバーレイで覆い隠す Chrome 拡張機能です。
見たくない情報を隠したり、離席時のプライバシー保護に活用できます。

## 機能

- **3つのテーマ** — Light / Dark / Glass（ぼかし強度調整可能）
- **ドラッグ移動** — オーバーレイを自由に移動
- **8方向リサイズ** — 角・辺のハンドルでサイズ調整
- **設定の自動記憶** — 位置・サイズ・テーマを自動保存、次回復元
- **ウィンドウ追従** — ウィンドウサイズ変更時にオーバーレイが中央配置レイアウトと同じ動きで追従
- **OS テーマ追従** — ポップアップ UI がブラウザのライト / ダークモードに自動追従
- **お問い合わせ** — ポップアップから Kagayoi Support へ問い合わせを送信

## 使い方

1. ツールバーのアイコンをクリック
2. テーマを選択（Glass の場合はぼかし強度も調整可能）
3. 「オーバーレイを表示」ボタンを押す

オーバーレイはドラッグで移動し、角・辺のハンドルでサイズを調整できます。閉じるには右上の × ボタンをクリックするか、Escape キーを押してください。

ポップアップの「リセット」で位置・サイズと保存済みのぼかし強度を初期化できます。

問い合わせはポップアップ下部の「お問い合わせ」から送信できます。初回送信時はメールで届く確認コードを入力します。

## インストール

配布 ZIP を利用する場合は、展開してから Chrome で `chrome://extensions` を開き、「デベロッパー モード」を有効にしてください。「パッケージ化されていない拡張機能を読み込む」から、`manifest.json` が入っているフォルダーを選択します。

ソースからの生成手順は [DESIGN.md のビルドと公開](DESIGN.md#ビルドと公開)、開発・検証の規約は [AGENTS.md](AGENTS.md) を参照してください。

## 表示できない場合

`chrome://` などブラウザの内部ページでは利用できません。通常の Web ページで試してください。表示に失敗した場合はポップアップに理由が表示されます。ローカルファイルで使う場合は、拡張機能の詳細画面で「ファイルの URL へのアクセスを許可する」を有効にしてください。

## 権限

| 権限 | 用途 |
|------|------|
| `activeTab` | 現在のタブにオーバーレイを表示 |
| `scripting` | オーバーレイ本体とスタイルを含むスクリプトの動的注入 |
| `storage` | 設定のローカル保存・復元 |
| `https://support.kagayoi.com/*` | 利用者が操作したときのメール確認と問い合わせ送信 |

オーバーレイの処理と設定保存は端末内で完結します。外部通信は、利用者が問い合わせを送信したときの Kagayoi Support との通信だけです。送信内容の詳細は[プライバシーポリシー](docs/privacy-policy.md)を参照してください。
